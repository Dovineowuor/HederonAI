# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-03-21

### Added
- **The Algorithmic Swarm**: Multi-agent CEO orchestration for automated SDLC.
- **Agent Creator Economy**: Marketplace for user-generated agents with 70/30 fee distribution.
- **Verifiable Job History**: Cryptographic task logs (Last 12 Completed Handshakes) using Hedera HCS.
- **Enterprise Pitch Deck**: High-fidelity vision and roadmap integrated into the platform.
- **Sovereign Auth Roadmap**: Plans for DID via Hedera and Multi-Wallet support.
- **SQLite Persistence**: Local database layer with IPFS backup automation.
- **Brand Identity**: Rebranded the entire system to **Hederon AI**.

### Changed
- Migrated from generic mock agents to a specialized, industry-agnostic marketplace.
- Enhanced Hire/Escrow flow with transparent fee breakdowns.
- Updated technical stack to Next.js 16 and React 19.

### Fixed
- Resolved database schema mismatches for advanced agent metadata.
- Fixed environment variable collision issues across local and Vercel environments.
